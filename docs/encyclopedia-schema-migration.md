# 百科字段升级

网站共享契约位于 FusionNexus 的 `portal/src/lib/encyclopedia-schema-revision.mjs`，
迁移执行器由本工具维护。新类型和字段通过数据库元数据进入采集上下文与前端。

先停止本工具的采集服务，避免迁移时继续写入。运行以下命令（路径由实际环境提供）：

```text
node scripts/migrate-encyclopedia-schema.mjs --database <维护数据库> --contract <共享契约文件> --backup <新建备份目录> --state <panel/state.sqlite> --apply
```

省略 `--apply` 只备份与演练。备份目录必须不存在。程序使用 SQLite backup 保存知识库与任务状态，
在系统临时目录复制完整备份并演练，检查完整性、外键、保留身份和证据、类型表数量和幂等性，
然后在实际数据库中提交事务并再次检查。备份目录中的 `manifest.json` 保存映射、删除 ID 与结果。
附件与原始来源文件不会被此迁移删除；恢复旧版本需停止采集与网站读写后同时恢复知识库、任务状态和旧版应用。

重新启动新版采集服务时，已确认且内容不变的字段保留处理进度；新增、合并和改变的字段待处理。
原先停止的任务不会自动继续，因新字段而不再完整的任务变为“完成部分”。事件与代码任务退出列表，历史审计保留。
装置时间轴按日期排序，未知日期放最后；科学词条 JSON 不限制键名。真实用户评价与论文原文结论必须有原始证据。

第 4 版补充会议确认的内容规则：零件供应商并入装置 `components`，保留零部件所属系统、使用阶段和替换历史；
时间轴节点有稳定 ID，区分计划与已发生、实验时间与公布时间，保留来源及资源关联。
网站只从有来源且明确已发生的状态变更计算运行状态；冲突日期或无法排序的状态记录不推断当前状态。
书籍按出版版本分别建词条，通过 `other_editions` 关联；论文增加 `versions`，译文独立保存在 `translations`。
原文摘要、内容概述、原文结论及外部用户评论分别标明，不互相替代。

机构原 `english_name` 合入身份 `name_en`；不同的旧值保存在别名中待复核，相关证据保留。
第 6 版解除人物、装置综合评定和论文历史引用资料等普通字段的采集冻结；身份字段仍只读，程序计算字段仍为 `system`。综合评定采集有来源的评价文字，不生成数值评分；历史引用资料须明确外部来源、统计时间与口径，不代替库内引用计算。
CAD、装置对标、课程进一步拆分和统一数据格式不在此版范围内。
迁移后会同步已有任务：内容或采集规则改变的字段重新待核查，其他已核对结果保留；不会自动启动任务。

导出继续按“已完成”任务筛选，打包同构数据库与关联附件；新增待处理字段的词条须重新完成后才进入导出。

第 5 版新增所有类型的四项数值评分、论文库内被引次数和高被引标记、期刊引用前十与投稿经验；机构统一使用三类分类和字段并集，发展历程迁入带类型的时间轴，补充团队、业务、投资项目、规模、资本性质、偏好及融资机会。期刊标识和年度指标复用既有字段，不另建同义列。旧引用量保留为待核历史资料。

此次迁移不采集事实，不给现有词条打分、不计算引用排名；新增系统字段保持空值。程序计算字段不计入采集任务和统计，后续由统一程序从完整数据重新计算。默认契约路径由 `dataRoot` 对应的 portal 目录解析；自定义部署可设置 `ENCYCLOPEDIA_CONTRACT_PATH`。程序来源覆盖评分不等于事实核验结论。

具体字段与公式参见 FusionNexus 的 `portal/docs/ENCYCLOPEDIA_FIELD_RULES.md`。升级后需重启采集工具并重建页面投影，使列表中的字段数、处理进度和状态与新字典一致。保留旧任务结果作为历史，原来停止的任务不自动启动。

从第 5 版升级到第 6 版只事务更新字段字典中的冻结模式和过期说明，不重建内容表，不改写正文、身份、证据或系统计算值。仍执行完整备份、隔离演练、完整性检查和任务范围对齐。普通字段恢复后重新纳入进度分母，缺少核查结果的已完成任务转为完成部分。
